02

Recursive DNS Server & Resolution Engine Networking & Java

A custom RFC 1035-compliant recursive DNS resolver engineered from scratch in Java using low-level UDP Datagram sockets and raw byte buffer manipulation, connected to a Python Flask REST API and web dashboard.

  • Binary Protocol Parsing: Hand-crafted binary packet parsing routines using Java ByteBuffer with Big-Endian byte ordering, decoding DNS header bit flags (QR, Opcode, RCODE), question labels, and resource records without external protocol libraries.
  • Dual-Resolution Strategy: Architected in-memory local caching with automatic recursive fallback querying to upstream public DNS servers (8.8.8.8) for unknown domain queries.
  • REST API & Web Interface: Built a Python Flask REST middleware and interactive frontend for real-time domain resolution, latency tracking, and robust error handling (NXDOMAIN, socket timeouts).
